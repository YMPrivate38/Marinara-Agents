# Fanfic Writer

Add the agent in Chat Settings → Agents → Writer Agents for Roleplay mode. After each reply it scores the reply 0-10 for staying in character and for making sense. If either score is below the minimum, the reply is rewritten to fix only those parts.

Settings: minimum score (default 7). It reads character cards, your persona and active lorebook entries to judge voice.

Chapter length, point of view and tense are now set per story in Story Writer.
